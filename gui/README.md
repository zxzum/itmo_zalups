# ITMO Loops GUI

Графический интерфейс для генератора музыки ITMO Loops на Qt6.

## Требования

- Qt6 (qt6-base-dev)
- C++20 компилятор
- CMake 3.24+

## Сборка

```bash
mkdir build
cd build
cmake ..
make
```

Исполняемый файл будет создан в `build/gui/itmoloops_gui`.

## Использование

### 1. Загрузка score файла

1. Нажмите "Обзор..." рядом с полем "Файл score.txt"
2. Выберите текстовый файл с описанием композиции
3. Папка samples будет установлена автоматически (если существует)
4. Нажмите "Загрузить"

### 2. Просмотр и редактирование

- **Редактор кода**: просмотр и небольшие правки score файла с подсветкой синтаксиса
- **Таблица инструментов**: показывает все инструменты из score
- **Список паттернов**: показывает все паттерны с их resolution
- **Сводка**: отображает BPM композиции

### 3. Генерация WAV

1. Укажите путь для выходного файла или используйте кнопку "Обзор..."
2. Нажмите "Сгенерировать WAV"
3. Дождитесь завершения генерации
4. Волновая форма появится в превью

### 4. Воспроизведение

Нажмите "Открыть в плеере" чтобы открыть сгенерированный WAV файл в системном аудиоплеере.

## Особенности

- **Тёмная тема**: современный темный интерфейс
- **Подсветка синтаксиса**: ключевые слова, числа, комментарии
- **Превью waveform**: визуализация сгенерированного аудио
- **Автоматическое определение путей**: GUI правильно обрабатывает относительные пути к samples
- **Русский интерфейс**: все надписи на русском языке

## Исправление проблемы с отсутствием звука

Эта версия исправляет критическую проблему с генерацией WAV файлов через GUI:

- Библиотека теперь поддерживает указание базовой директории для поиска `notes.txt` и samples
- Относительные пути к sample файлам автоматически преобразуются в абсолютные
- Три новые функции в lib:
  - `run_itmoloops(inFile, outFile, baseDir)` - с указанием базовой директории
  - `run_itmoloops_from_string(scoreContent, outFile, baseDir)` - генерация из строки

## Структура кода

- `main.cpp` - точка входа
- `mainwindow.{hpp,cpp}` - главное окно приложения
- `syntaxhighlighter.{hpp,cpp}` - подсветка синтаксиса для редактора
- `waveformwidget.{hpp,cpp}` - виджет отображения волновой формы
